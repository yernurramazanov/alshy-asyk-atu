# Alshy

Современная браузерная адаптация казахской национальной игры асық ату. Игрок выбирает направление и силу броска сақа, чтобы выбить асыки за границу круга.

## Возможности

- физические столкновения на Phaser Matter Physics;
- полный раунд: 15 асыков, цель — выбить 8;
- единое соревновательное управление жестом мыши или касанием;
- обучение, классический режим и три испытания;
- звёзды за мастерство, монеты за новые достижения и лавка сақа;
- сохранение прогресса, покупок, истории результатов и рекорда в профиле;
- адаптивный интерфейс для компьютера и телефона.

## Правила цифровой адаптации

1. Игрок ведёт сақа к цели: направление жеста задаёт угол, длина — силу.
2. После отпускания сақа результат рассчитывает физический движок.
3. Асык засчитывается, только если полностью вышел за светлую границу круга.
4. В классическом режиме нужно выбить 8 из 15 асыков за 10 бросков.
5. Один асык нельзя засчитать повторно.

Ограничение бросков, испытания, статистика, звёзды и лавка являются авторскими дополнениями цифровой версии. Новые звёзды дают по 20 монет, первая победа в обучении — 20; повторение прежнего результата монет не даёт. Резное дерево меняет только вид сақа, тяжёлый бронзовый и лёгкий серебряный варианты меняют физику броска с компромиссом.

## Запуск

```bash
npm install
npm run dev
```

Production build: `npm run build`.

## Управление

- мышь или касание: зажать сақа, провести указателем в сторону цели и отпустить;
- короткое нажатие без протягивания не считается броском.

## Технологии

TypeScript, React, Vinext/Vite, Phaser, Matter Physics и Cloudflare D1 для прогресса игрока.

## AI и сторонние компоненты

Проект разработан с помощью OpenAI Codex. Использованы Phaser, Matter Physics, Lucide Icons и компоненты стартового набора Sites. Орнаментальная лента с мотивом қошқар мүйіз создана встроенной моделью генерации изображений OpenAI специально для проекта. Игровая логика, правила адаптации и визуальная система созданы для Alshy.

## Известные ограничения

- сохранение прогресса требует входа в закрытый сайт;
- мультиплеер отсутствует;
- физическая форма асыка упрощена для стабильной 2D-симуляции;
- аудиоресурсы ещё не добавлены.
