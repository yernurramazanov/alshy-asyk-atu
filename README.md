# ALSHY — асық ату в браузере

ALSHY — самостоятельная 2D-адаптация казахской национальной игры асық ату. Она рассчитана на тех, кто хочет познакомиться с игрой, и на игроков, которым интересно улучшать точность броска. Играть можно на компьютере и телефоне без регистрации.

## Что реализовано

- Физический полёт сақа, столкновения и движение асыков на Phaser Matter Physics.
- Бросок одним жестом мыши или касанием: направление и длина движения задают угол и силу.
- Обучение, классический раунд и три испытания с постепенно возрастающей сложностью.
- Рекорд, история восьми последних раундов, звёзды, монеты и лавка четырёх сақа.
- Казахский, русский и английский интерфейс; светлая и тёмная темы.
- Сохранение прогресса в `localStorage` текущего браузера без сервера и аккаунта.

## Правила этой версии

Игрок запускает сақа в группу из 15 асыков. Асык приносит одно очко после полного выхода за светлую границу круга; повторный подсчёт одного и того же асыка невозможен. В классическом режиме нужно выбить 8 асыков не более чем за 10 бросков. Обучение требует выбить один асык за 4 броска. Отдельные испытания предлагают выбить 3 асыка одним броском, сделать серию из двух удачных бросков и выбить 8 асыков за 6 бросков.

Чтобы бросить, зажмите сақа, потяните указатель в сторону цели и отпустите. Короткое нажатие без протягивания броском не считается. После удара дождитесь остановки фигур: результат подсчитывается по их конечному положению.

Это **цифровая адаптация**, а не официальный регламент соревнований. Круглая арена, количество асыков и бросков, режимы, звёзды, монеты и различия между сақа — авторские игровые решения. Деревянный сақа меняет внешний вид; бронзовый тяжелее и медленнее, серебряный легче и быстрее. Монеты выдаются за первую победу в обучении и за новые звёзды, но не за повторение прежнего результата.

## Запуск локально

Нужен Node.js 22.13+ и npm.

```bash
npm ci
npm run dev
```

Откройте `http://localhost:3000`. Проверка production-сборки: `npm run build`; статический результат появится в `out/`. Переменные окружения и база данных не нужны.

## Публикация на Vercel

Импортируйте этот репозиторий в Vercel как проект Next.js. Корневая директория — корень репозитория, команда сборки — `npm run build`; дополнительных переменных окружения нет. `next.config.ts` включает статический экспорт, поэтому Vercel размещает готовые файлы из `out/`. Публичная ссылка на Vercel и исходный код на GitHub должны относиться к одному коммиту.

## Технологии и использование AI

TypeScript, Next.js 16, React 19, Phaser 4/Matter Physics, Tailwind CSS, Lucide Icons и UI-компоненты на основе shadcn. Проект разработан при помощи OpenAI Codex: AI помогал с кодом, текстами, интерфейсом и проверками. Орнаментальный графический мотив создан генератором изображений OpenAI специально для проекта. Игровые правила, физика, экономика и композиция интерфейса адаптированы для ALSHY; сторонние библиотеки перечислены в `package.json`.

## Известные ограничения

- Прогресс хранится только в этом браузере. На другом устройстве или после очистки данных браузера он не восстановится; синхронизации аккаунта и общей таблицы лидеров нет.
- Очки и монеты рассчитываются в браузере и не защищены от ручного изменения локального хранилища. Это одиночная игра, не соревновательный сервер.
- Форма асыка и поведение удара упрощены для стабильной 2D-физики; мультиплеера и звука пока нет.
