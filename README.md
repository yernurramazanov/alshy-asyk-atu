# Alshy

Современная браузерная адаптация казахской национальной игры асық ату. Игрок выбирает направление и силу броска сақа, чтобы выбить асыки за границу круга.

## Возможности

- физические столкновения на Phaser Matter Physics;
- полный раунд: 15 асыков, цель — выбить 8;
- управление мышью, касанием, клавиатурой и ползунками;
- обучение, классический режим и три испытания;
- локальный прогресс, история результатов и рекорд;
- адаптивный интерфейс для компьютера и телефона.

## Правила цифровой адаптации

1. Игрок задаёт направление и силу броска.
2. После отпускания сақа результат рассчитывает физический движок.
3. Асык засчитывается, только если полностью вышел за светлую границу круга.
4. В классическом режиме нужно выбить 8 из 15 асыков за 10 бросков.
5. Один асык нельзя засчитать повторно.

Ограничение бросков, испытания, статистика и прогресс являются авторскими дополнениями цифровой версии.

## Запуск

```bash
npm install
npm run dev
```

Production build: `npm run build`.

## Управление

- мышь или касание: потянуть сақа назад и отпустить;
- `←` и `→`: изменить угол;
- `↑` и `↓`: изменить силу;
- `Space`: бросок;
- ползунки и кнопка «Бросить сақа» — альтернативное управление.

## Технологии

TypeScript, React, Vinext/Vite, Phaser, Matter Physics и локальное хранилище браузера.

## AI и сторонние компоненты

Проект разработан с помощью OpenAI Codex. Использованы Phaser, Matter Physics, Lucide Icons и компоненты стартового набора Sites. Игровая логика, правила адаптации и визуальная система созданы для Alshy.

## Известные ограничения

- прогресс пока хранится только в браузере;
- мультиплеер отсутствует;
- физическая форма асыка упрощена для стабильной 2D-симуляции;
- аудиоресурсы ещё не добавлены.
