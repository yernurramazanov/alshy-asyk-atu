# ALSHY — асық ату в браузере

ALSHY — самостоятельная 2D-адаптация казахской национальной игры асық ату. Она рассчитана на тех, кто хочет познакомиться с игрой, и на игроков, которым интересно улучшать точность броска. Играть можно на компьютере и телефоне без регистрации.

[Открыть игру](https://alshy-asyk-atu.vercel.app)

## Что реализовано

- Физический полёт сақа, столкновения и движение асыков на Phaser Matter Physics.
- Бросок одним жестом мыши или касанием: направление и длина движения задают угол и силу.
- Обучение, классический раунд и три испытания с постепенно возрастающей сложностью.
- Рекорд, история восьми последних раундов, звёзды, монеты и лавка четырёх сақа.
- Казахский, русский и английский интерфейс; светлая и тёмная темы.
- Сохранение прогресса в `localStorage` текущего браузера без сервера и аккаунта.

## Как играть

1. Откройте игру и нажмите **«Начать обучение»** для первого броска или **«Выбрать режим»** для самостоятельной игры. Кнопка **«Правила»** в верхней части экрана объясняет механику прямо в приложении.
2. Найдите свой сақа под кругом (по умолчанию он бирюзовый). Зажмите его левой кнопкой мыши или пальцем и ведите указатель **вверх, в сторону асыков**. Направление жеста задаёт угол броска, его длина — силу. Линия прицеливания показывает направление броска.
3. Отпустите кнопку или палец, чтобы бросить сақа. Простое нажатие без движения не запускает бросок. Пока асыки движутся, следующий бросок недоступен.
4. Дождитесь окончания движения. Каждый асык, полностью оставшийся за светлой границей круга, приносит **1 очко**. Счёт и число оставшихся бросков показаны в карточке результата рядом с полем (на телефоне — над полем).
5. Продолжайте, пока не выполните цель режима или не закончатся броски. На экране результата можно повторить раунд, вернуться к режимам или перейти в лавку.

Мышь и касание работают одинаково; отдельной кнопки броска и прицеливания с клавиатуры нет. В верхней панели можно переключить язык (қазақша, русский, English) и светлую/тёмную тему.

### Цели режимов

| Режим | Цель | Лимит |
| --- | --- | --- |
| Обучение | Выбить 1 асык | 4 броска |
| Классический раунд | Выбить 8 асыков суммарно | 10 бросков |
| Мощный удар | Выбить не менее 3 асыков одним броском | 4 броска |
| Серия | Сделать 2 результативных броска подряд | 7 бросков |
| Нағыз мерген | Выбить 8 асыков суммарно | 6 бросков |

«Классический раунд» и «Мощный удар» доступны сразу; следующие испытания открываются по мере побед. За новые достижения начисляются звёзды и монеты. В лавке можно купить и выбрать другой сақа: деревянный меняет внешний вид, бронзовый тяжелее и медленнее, серебряный легче и быстрее. Прогресс сохраняется автоматически в текущем браузере.

## Правила этой версии

Игрок запускает сақа в группу из 15 асыков. Один асык можно засчитать только один раз. В этой версии очко присуждается, если к моменту завершения броска физическое тело асыка полностью оказалось за границей круга.

Это **цифровая адаптация**, а не официальный регламент соревнований. Круглая арена, количество асыков и бросков, режимы, звёзды, монеты и различия между сақа — авторские игровые решения. Монеты выдаются за первую победу в обучении и за новые звёзды, но не за повторение прежнего результата.

## Запуск локально

Нужен Node.js 22.13+ и npm.

```bash
npm ci
npm run dev
```

Откройте `http://localhost:3000`. Проверка production-сборки: `npm run build`; статический результат появится в `out/`. Переменные окружения и база данных не нужны.

## Публикация на Vercel

Импортируйте этот репозиторий в Vercel как проект Next.js. Корневая директория — корень репозитория, команда сборки — `npm run build`; дополнительных переменных окружения нет. `next.config.ts` включает статический экспорт, поэтому Vercel размещает готовые файлы из `out/`. Публичная ссылка на Vercel и исходный код на GitHub должны относиться к одному коммиту.

## Технологии и использование AI

TypeScript, Next.js 16, React 19, Phaser 4/Matter Physics, Tailwind CSS, Lucide Icons и UI-компоненты на основе shadcn. Проект разработан при помощи OpenAI Codex: AI помогал с кодом, текстами, интерфейсом и проверками. Орнаментальный графический мотив создан генератором изображений OpenAI специально для проекта. Игровые правила, физика, экономика и композиция интерфейса адаптированы для ALSHY; сторонние библиотеки перечислены в `package.json`.

## Известные ограничения

- Прогресс хранится только в этом браузере. На другом устройстве или после очистки данных браузера он не восстановится; синхронизации аккаунта и общей таблицы лидеров нет.
- Очки и монеты рассчитываются в браузере и не защищены от ручного изменения локального хранилища. Это одиночная игра, не соревновательный сервер.
- Форма асыка и поведение удара упрощены для стабильной 2D-физики; мультиплеера и звука пока нет.
